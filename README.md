Windows Server 2022 & Active Directory Lab

Project Overview

This project documents a hands-on IT infrastructure lab built using VMware Workstation and Windows Server 2022.

The lab focuses on learning Windows Server administration, Active Directory, DNS, Group Policy, user and group management, and basic PowerShell administration.

The goal is to simulate a small business IT environment and gain practical experience with common system administration and IT support tasks.

Lab Environment

| Component | Configuration |
|---|---|
| Virtualization Platform | VMware Workstation |
| Server Operating System | Windows Server 2022 Standard Evaluation |

Technologies & Tools

- Windows Server 2022
- Active Directory Domain Services (AD DS)
- DNS
- Group Policy (GPO)
- PowerShell
- VMware Workstation
- Windows 11 Pro (Domain Client)

Learning Objectives

- Install and configure Windows Server.
- Configure static IP addressing and DNS.
- Understand and deploy Active Directory Domain Services.
- Create and manage domain users, groups, and Organizational Units (OUs).
- Join Windows client machines to a domain.
- Configure and test Group Policy Objects (GPOs).
- Configure shared folders and access permissions.
- Perform basic Windows Server administration using PowerShell.
- Troubleshoot common network and domain-related issues.
